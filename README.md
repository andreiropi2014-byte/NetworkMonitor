# Network Monitor System

## 📋 Описание проекта
Система мониторинга сетевых устройств с клиент-серверной архитектурой. Приложение позволяет сканировать сеть, обнаруживать активные устройства, мониторить их доступность и собирать статистическую информацию.

## 🎯 Основные функции
- **Сканирование сети** с использованием различных методов:
  - ICMP Ping сканирование
  - TCP порт сканирование
  - ARP сканирование
  - Комбинированное сканирование
- **Обнаружение активных устройств** в указанной сети
- **Мониторинг доступности** в реальном времени
- **Графическая визуализация** статистики
- **Экспорт результатов** в CSV формате
- **История сканирований** с возможностью просмотра

## 🏗️ Архитектура
Проект состоит из трех основных компонентов:

### 1. **NetworkMonitor.Shared**
- Общие модели данных (DeviceInfo, ScanRequest, ScanResult)
- Утилиты для сериализации и работы с CIDR
- Используется как клиентом, так и сервером

### 2. **NetworkMonitor.Server**
- TCP сервер на порту 5000
- Логика сканирования сетей
- Обработка клиентских запросов
- Логирование событий

### 3. **NetworkMonitor.Client**
- WPF приложение с графическим интерфейсом
- Управление сканированием и мониторингом
- Визуализация результатов
- Графики статистики
